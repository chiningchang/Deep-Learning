Chapter 01 / Artificial Neural Networks

Learning patterns through connections.

Artificial neural networks (ANNs) are models made of connected mathematical functions called neurons or nodes. During training, the model adjusts the weights and biases of those connections to learn patterns in data.

Their design is loosely inspired by biological neurons. Artificial neurons perform numerical calculations; the analogy does not mean they work like a complete human brain.

ANNs can model complex, nonlinear relationships for regression and classification. They are foundational to deep learning. Other architectures build on these concepts, including convolutional networks, recurrent networks, and Transformers.

Predicting a number, such as an assessment score.

Hidden layers and deep learning

A simple network may have one hidden layer. A network with multiple hidden layers is commonly called a deep neural network (DNN), and training these networks is part of deep learning. Additional layers can build more complex representations, but adding layers does not guarantee better performance.

The number of hidden layers and the number of nodes in each layer are hyperparameters: design choices set before training. Researchers often compare these choices using validation data or cross-validation. Final test data should remain separate from that tuning process.

Inputs are features in the model’s numeric representation. A categorical feature may need multiple encoded inputs; a single raw variable does not always correspond to a single node.

In plain language

Feature
One piece of information used to make a prediction, such as the number of discussion posts.
Scaled 0–1
The inputs are put on a common numerical scale. For example, 0 may represent the low end and 1 the high end.
Hyperparameter
A model setting chosen before training, such as the number of hidden nodes.
Validation / cross-validation
Ways to compare model settings using examples set aside from the weight-fitting process. Cross-validation repeats this using different splits.
Encoding a category
Representing a label with numbers the network can process. A category can sometimes require several input values.
02 / The prediction task

The output layer fits the task.

The number of output nodes and the output activation depend on what the model is trying to predict.

A number or a category?

Regression: commonly one linear output for one continuous outcome, such as a predicted score.

Binary classification: commonly one sigmoid output for the probability of one of two classes.

Multi-class classification: commonly one output per mutually exclusive class, with softmax converting class scores into probabilities that sum to 1.

These are common designs rather than universal rules. Binary classification can also use two softmax outputs. Multi-output regression and multilabel tasks use other arrangements.

A connection has a weight

Strength and direction.

A positive weight means increasing that input increases this neuron’s weighted sum, holding the other values fixed.

A negative weight means increasing that input decreases the sum. A weight of zero removes its direct contribution to this neuron.

The bias shifts the sum even when all inputs are zero.

Explore more: a weight is not an explanation

A single connection describes a local calculation. Its weight alone does not explain the feature’s total effect across a multilayer network.

Numbers or categories?

Predict a number: an output can use a linear function, allowing values beyond 0–1.

Predict one of two classes: a single sigmoid output is a common design.

Predict one of several classes: softmax can turn a set of class scores into nonnegative outputs that sum to 1.

Try a three-class output

Class B and C scores stay at 0.5 and −0.5. Softmax outputs sum to 100%, but that alone does not guarantee calibrated probabilities.

Does activation mean on or off?

Not always. Sigmoid and tanh have smooth outputs. ReLU outputs zero for nonpositive inputs and passes positive inputs through. The function controls a numerical transformation, not a conscious decision.

In plain language

Softmax
Turns several class scores into a set of outputs that add up to 100%.
Calibrated probabilities
If many similar predictions say “80%,” roughly 80% should be correct. Adding up to 100% does not, by itself, establish this reliability.
05 / How ANNs learn

Learning means updating weights and biases.

The network makes a prediction, compares it with a known outcome, computes gradients through backpropagation, and uses an optimizer to update its parameters. Repeating this cycle can improve predictions.

In plain language

Loss / error
A number showing how far a prediction is from its known target. Smaller loss usually means a closer fit to that example.
Gradient
A signal showing how the loss would change if a weight or bias changed a little.
Backpropagation
Working backward through the calculations to find those change signals.
Optimizer / learning rate
The optimizer is the update rule. The learning rate controls the size of its steps.

How does a bias change?

A bias is added directly to its neuron’s weighted sum. Its derivative at that addition is 1, so its gradient is the neuron’s error signal.

new bias = old bias − learning rate × bias gradient

The hidden bias gets its own gradient through the output connection. It does not simply copy the output bias’s update.

From one example to many epochs

A forward pass produces a prediction. A loss function measures how it differs from the target. Backpropagation calculates how each parameter affects that loss, and an optimizer updates the weights and biases.

An epoch is one pass through the full training set, rather than one single-example update. Training usually involves many updates over many epochs. Progress can fluctuate, and better training results do not guarantee better results on new data.

06 / Variable importance

What contributes to the prediction?

A network’s computations can be inspected, yet its combined transformations may be difficult to explain in familiar terms. This is why ANNs are often described as “black-box” models.

Garson’s method

For a common single-hidden-layer network setting, Garson’s method uses the magnitudes of connection weights to estimate relative input importance.

Because it uses absolute weights, it generally summarizes relative strength without preserving the direction of an effect.

Olden’s algorithm

Olden’s approach combines signed connection-weight products along paths from inputs to an output.

Keeping the signs allows positive and negative contributions to offset one another. Its interpretation depends on the network and output being examined.

In plain language

Variable importance
A summary of how strongly an input contributes to a fitted model’s predictions.
Magnitude / absolute weight
The size of a number without its positive or negative sign: −3 and +3 both have magnitude 3.
Signed contribution
Keeping the positive or negative direction when combining contributions.
Not causation
An input can help predict an outcome without being the cause of that outcome.
These methods describe the fitted model. Importance does not establish causation, and weight-based summaries do not fully explain every individual prediction. Feature scaling can also affect comparisons.
Why doesn’t one large weight tell the whole story?

An input can influence multiple hidden nodes through several paths. Later weights, activation functions, and other inputs affect how these signals combine. A weight in one connection is not automatically the feature’s total importance.

07 / Strengths and limitations

What ANNs offer. What they require.

ANNs are flexible tools, but their usefulness depends on the data, the task, the model design, and the quality of evaluation.

Strengths and limitations at a glance
StrengthsLimitations and considerations
Complex relationships
Can represent nonlinear patterns and interactions.		Interpretability
Multiple transformations can make predictions hard to explain.
Predictive potential
Can perform well with suitable data, design, and training.		Data requirements
Large networks can need substantial data. Strong accuracy is not guaranteed.
Flexible outputs
Can support regression and classification.		Overfitting
A complex model can fit training data without generalizing well.
Learned representations
Adjust weights and biases to learn useful combinations of inputs.		Computation
Training and tuning larger networks can demand time and computing resources.
Adaptable architecture
Depth, width, and activations can be tailored to the task.		Tuning choices
Selecting layers, nodes, and training settings requires comparison and experimentation.

In plain language

Overfitting
Doing very well on practice examples but less well on new ones, like memorizing answers instead of learning a general pattern.
Generalization
How well a learned pattern works on examples the model did not train on.
Interpretability
How easily people can explain why the model made a prediction.
ANNs do not automatically outperform statistical or other machine-learning models. Many statistical methods can also model nonlinear relationships. Compare appropriate alternatives on the same prediction task.
